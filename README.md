# 課堂節拍器

給流行音樂課使用的網頁節拍器，可以在教室用投影機或手機操作。整個程式只有一個 HTML 檔，不需要網路。

## 使用方式

- **線上開啟**：開啟本儲存庫的 GitHub Pages 網址（需先在 Settings → Pages 啟用）。
- **離線使用**：下載 `index.html`，直接用瀏覽器打開。

## 功能

- BPM 範圍 40–240，有紅色 LED 大數字顯示，可用推桿、±1／±5 按鍵（按住可連續調整）或 Tap Tempo 設定速度。
- 拍號可選 2/4、3/4、4/4、6/8。6/8 以八分音符計速，每小節 6 響。
- 第 1 拍用較高音的重音；6/8 的第 4 拍是次重音，音高介於重音和一般拍之間。
- 打擊墊跟著節拍亮起，和聲音同步。
- 播放時保持螢幕常亮，並記住上次使用的速度和拍號。

## 鍵盤快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| 空白鍵 | 開始／停止 |
| ↑ ↓ | BPM ±1 |
| ← → | BPM ±5 |
| T | 打拍（Tap Tempo） |
| 1–4 | 切換拍號 2/4、3/4、4/4、6/8 |

## 注意事項

- iPhone 若開著側邊的靜音開關，網頁可能不會出聲，請先關掉靜音。
- 播放中切換拍號，會從新拍號的第 1 拍重新開始。
